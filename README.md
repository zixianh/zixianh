## About

I study **how AI changes the way people use information**, and **how to draw reliable conclusions when model outputs are used as data**. My work brings together causal inference, uncertainty quantification, and LLM evaluation, with applications to online knowledge platforms and computational social science.

The question started in industry. As a data analyst, I relied on AI-generated code to clean and restructure data, and watched it fill ambiguous instructions with unstated assumptions: code that ran without error, yet was quietly wrong. My research is about failures like these.

**When Better Codebooks Are Not Enough: Predictive Performance and Rule Adherence in LLM Political Event Coding**<br/>
<b>Zixian He</b>, Bharath Raahul Murugesan, Patrick T. Brandt, Yibo Hu

Do LLMs actually follow the expert codebooks they are given? Richer codebooks raise accuracy on political event coding (macro-F1 0.457 → 0.633), yet reversing the order of codebook entries, with every definition unchanged, alters 21% of predictions.

[![Paper](https://img.shields.io/badge/Paper-3B5B85?style=flat-square)](https://arxiv.org/abs/2606.06781)
[![Code](https://img.shields.io/badge/Code-3B5B85?style=flat-square)](https://github.com/yibo-hu-lab/event-coding-reliability)

<details>
<summary><sub>METHODS</sub></summary>
<br/>
Controlled codebook changes (reordered entries, placeholder label names, reassigned definitions) separate classification accuracy from adherence to the supplied rules. Agreement across orderings is measured with Fleiss' κ; differences between conditions with bootstrap confidence intervals, across four open-source LLMs.
</details>

<td valign="top">

**How Wikipedia Readership Shifted after ChatGPT**<br/>
<b>Zixian He</b>, with Xinyu Chen and Ambra Amico

How do you estimate the effect of a technology that reaches everyone at once? Placebo analyses back to 2015 show that much of the apparent post-ChatGPT decline reflects recurring seasonality; the remaining evidence points to a shortfall concentrated in computing articles.

<details>
<summary><sub>METHODS</sub></summary>
<br/>
A daily pageview panel of 10,000 English Wikipedia articles, built from raw hourly Wikimedia dumps. Counterfactual readership estimated with nuclear-norm-regularized matrix completion, benchmarked against synthetic control and difference-in-differences through pseudo-treatment validation, with split conformal prediction intervals.
</details>
